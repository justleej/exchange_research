# Hybrid(ARIMA + LSTM) walk-forward 검증 계획 (결과를 보기 전에 작성)

원 캡스톤의 Hybrid 모델(ARIMA가 수익률의 선형 부분을 잡고 LSTM이 잔차를 보정)을, 같은 walk-forward 표본에서
무변화 기준선(RW)과 ARIMA 단독, 그리고 유동성(MMF) 추가 여부와 비교한다. 이전 Hybrid 검증은 단일 분할(2023-02-09)과 축소판이었다.

## 고정 설정 (튜닝 금지, 한 번만 실행)
- 표본: `walkforward_daily.py`와 같은 평가 원점(2009-12~2026-03). 학습에는 목표가 원점까지 실현된 관측만 쓴다.
- ARIMA(1,0,1) 무평균을 252원점마다 원점까지의 일별 로그수익률로만 재추정한다. 5일 누적 예측은 직전 1단계 예측에 phi^(h-1)을 곱해 합산한다.
- LSTM 보정: 목표는 (실제 5일 수익률 - ARIMA 5일 예측). 입력은 30일 시퀀스. 은닉 32, 20 epoch, 학습률 0.001, 시드 3개 평균, 252원점마다 재추정.
- 변형: ARIMA 단독 / Hybrid 기본[ARIMA 잔차, 수익률, 금리차 1일 변화] / Hybrid+MMF[기본 + MMF 1일 로그 변화].

## 가설과 판정 기준
- H7a: 어느 변형도 전체 표본에서 RW 대비 RMSE 비율이 1 미만이면서 DM p<0.05가 되지 않는다. (3개 변형 x 3개 표본[전체, 안정, 고변동] 9개를 한 군으로 Holm 보정)
- H7b: LSTM 보정(Hybrid 기본)이 ARIMA 단독보다 낫지 않다(비율이 1 이상이거나 DM p>=0.05).
- H7c: MMF 추가(Hybrid+MMF)가 Hybrid 기본보다 낫지 않다(비율이 1 이상이거나 DM p>=0.05).
- 방향 정확도는 이항검정(0.5 대비)을 같은 9개 군에서 Holm 보정해 계획 안에서 본다.

## 범위 밖 (원 코드와의 차이를 미리 밝힌다)
- 원 코드의 하이퍼파라미터 탐색(HPO)과 CNN-LSTM 변형은 포함하지 않는다. walk-forward 안에서 탐색하면 계산량이 크고 탐색이 평가 표본에 과적합될 위험이 있어서 고정 설정만 쓴다. 그래서 이 결과는 "원 코드의 Hybrid 전체"가 아니라 같은 구조의 고정 설정 버전이다.
- 결과가 기대와 달라도 설정과 기준을 바꾸지 않는다.
