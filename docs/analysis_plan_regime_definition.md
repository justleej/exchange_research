# 변동성 레짐 정의 점검 계획 (결과 확인 전에 작성)

목적: 변동성 구간별 conformal 95% 구간(`confr`)이 쓰는 "안정/고변동" 구분(원점의 20일 실현변동성이 과거 67% 분위수 초과)이
임의로 정한 것은 아닌지, 다른 합리적 정의가 구간 품질을 더 좋게 하는지 확인한다. 자료는 무료 자료(기존 파일 + data/oos)만 쓴다.

## 비교 정의 (이 4개로 끝, 결과를 보고 더하지 않는다)

| 이름 | 정의 (모두 원점까지의 값만 사용) |
|---|---|
| R0 기준 | 20일 실현변동성 > 과거 67% 분위수 (현행) |
| R1 3구간 | 20일 실현변동성의 과거 33%, 67% 분위수로 저/중/고 |
| R2 EWMA | EWMA(0.94) 변동성 > 과거 67% 분위수 |
| R3 60일 | 60일 실현변동성 > 과거 67% 분위수 |
| R4 HMM | 2상태 Markov 전환(평균 공통, 분산 전환) 일수익률(%) 모형. 매 252거래일 블록 시작까지의 자료로만 모수를 추정하고, 필터링 확률(그날까지 자료만 사용)이 0.5 초과인 큰 분산 상태를 고변동으로 본다 |

변동성 척도 sigma, 보정 창(750), 수준(95%)은 현행과 같다. 바꾸는 것은 레짐 라벨뿐이다.

## 지표와 판정 (원점은 모두 R0~R4의 구간이 있는 날로 맞춘다)

- 지표: 95% 구간의 Winkler 점수 평균(작을수록 좋음), 전체와 레짐별 커버리지.
- H10a: 대안 Rk의 평균 점수가 R0보다 낮고, 쌍체 이동 블록(20일) 부트스트랩 차이의 95% 신뢰구간 상한이 0 미만. 대안 4개에 Holm 보정.
- H10b(안전 조건): 대안의 전체 커버리지가 93~97%, 모든 레짐 커버리지가 92% 이상.
- "채택" = H10a와 H10b 모두 충족. 충족하는 대안이 없으면 현행 정의를 유지한다고 적는다.
- 보조: 표본을 2026-03-16 전/후로 나눠 보고(후 구간은 170개 원점이라 판정에는 쓰지 않음), R0 대비 R1~R4 점수 차이의 부호가 두 구간에서 같은지 적는다.

## 하지 않는 것

- 레짐 개수나 분위수를 점수를 보고 조정하지 않는다(위 정의 1회 실행).
- 헤지 시뮬레이션(H8)을 새 레짐으로 다시 돌리지 않는다. 채택된 대안이 있을 때만 다음 단계로 제안한다.
- 프로젝트 전체 다중검정 보정은 범위 밖이다.
