# 모델 확장 검증 계획 (결과를 보기 전에 작성)

지금까지의 모델은 선형(AR, 금리차, MMF)과 LSTM(단일 분할)이었다. "더 복잡한 모델이면 무변화 기준선을 이기는가"를
같은 walk-forward 표본과 같은 기준으로 확인하고, 의사결정 입력인 변동성 모델도 한 단계 더 정교한 것(GARCH-t)과 비교한다.
모델 수를 늘리는 것이 목적이 아니라, 복잡도를 올려도 결론이 바뀌는지를 공정한 평가로 확인하는 것이다.

## 고정 규칙 (튜닝 금지)
- 평가 표본: `analysis/walkforward_daily.py`의 평가 원점(2009-12~2026-03)과 같다. 학습에는 목표가 원점까지 실현된 관측만 쓴다.
- 하이퍼파라미터는 아래에 적은 값으로 **고정**하고, 결과를 보고 바꾸지 않는다. 한 번만 돌리고 전부 보고한다.
- 특성(원점에서 아는 값): r1, r5, r20, r60(환율 수익률), ds5(금리차 5일 변화), 금리차 수준, dm5, dm20(MMF 5일, 20일 로그 변화, 1일 지연), vol20.

## 모델 (고정 설정)
- Ridge(alpha=10, 학습 구간에서 표준화), 63원점마다 재추정
- 랜덤 포레스트(트리 200개, 최대 깊이 4, 리프 최소 50, 시드 0), 63원점마다 재추정
- 그래디언트 부스팅(트리 200개, 깊이 2, 학습률 0.03, 부분표본 0.7, 시드 0), 63원점마다 재추정
- LSTM(은닉 32, 30일 시퀀스[r1, 금리차 1일 변화, MMF 1일 로그 변화], 20 epoch, 학습률 0.001, 시드 3개 평균), 252원점마다 재추정
- 변동성: GARCH(1,1)-t(scipy 최대우도, 252원점마다 재추정), 구간은 기존과 같은 구간별 conformal

## 가설과 판정 기준
- H5a: 어느 모델도 전체 표본에서 RW 대비 RMSE 비율이 1 미만이면서 DM p<0.05가 되지 않는다. (하나라도 되면 "그 모델에 한해 개선 근거"로 기록하되 Holm 보정 후 판정한다.)
- H5b: 모델별 방향 정확도의 95% 신뢰구간이 0.5를 포함한다(방향 우위 없음). 구간이 0.5 위에 있으면 "방향 우위 후보"로 기록한다.
- H5c: 안정기와 고변동기로 나눠 보더라도 위 두 가지는 달라지지 않는다. 검정은 (4개 모델 x 3개 표본[전체, 안정, 고변동]) 12개를 한 군으로 Holm 보정한다.
- H6: GARCH-t로 만든 구간별 conformal의 Winkler 점수가 80%와 95% 모두에서 EWMA(0.94)보다 낮을 때만 의사결정 입력으로 채택한다. 하나라도 높거나 같으면 EWMA를 유지한다.

## 범위 밖
- 하이퍼파라미터 탐색, 새 특성 추가, 모델 추가는 이번 계획에서 하지 않는다. 결과가 기대와 달라도 계획을 바꾸지 않는다.
