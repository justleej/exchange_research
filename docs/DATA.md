## 시점 규칙 (미래 정보 방지)
- 월별 자료: 해당 월 말 다음 달 말부터 사용 가능하다고 가정한다. 민감도로 2개월 지연도 확인했다.
- 일별 금리차, MMF: 직전 관측(당일 제외)만 사용한다.
- walk-forward 평가: 원점 t에서 목표가 t까지 실현된 관측만 학습에 쓴다. T 이후 자료를 바꿔도 T까지의 결과가 같은지 `tests/run_tests.py`로 확인한다.

## 단위 변환과 점검
- 포털에서 받은 새 MMF와 CMA 파일은 억원 단위이므로 10으로 나눠 기존 십억원 자료와 맞춘다.
- 자료 일치 점검(환율 원본 대 가공본, MMF와 CMA 새 자료 대 기존 자료)은 `tests/run_tests.py`의 `test_data_integrity`가 한다.
